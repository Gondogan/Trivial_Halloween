# 🎃 Trivial de Halloween - Escape Room Interactivo

Bienvenido al repositorio oficial del **Trivial de Halloween**, una aplicación web interactiva diseñada como prueba principal para un Escape Room infantil. 

Este proyecto es una colaboración interdisciplinar entre el departamento de Informática (Desarrollo de la aplicación) y los alumnos de 1º de Educación Infantil (Diseño pedagógico y pruebas).

---

## 🛠️ Stack Tecnológico y Herramientas

El proyecto está construido con un stack moderno de JavaScript, centrado en la interactividad y la experiencia de usuario:

*   **Frontend:** React, HTML5, CSS3, JavaScript.
*   **Entorno:** Node.js
*   **Diseño y Maquetación:** Figma
*   **Gestión de Proyecto:** Trello

---

## 🎯 Objetivos del Proyecto

1.  **Interactividad:** Crear una interfaz atractiva y fácil de usar para un público infantil, con temática de Halloween.
2.  **Gamificación:** Implementar un sistema de preguntas y respuestas dinámico que sirva como "llave" para avanzar en el Escape Room.
3.  **Trabajo en equipo:** Coordinar los requisitos pedagógicos de Educación Infantil con la viabilidad técnica del desarrollo web.
